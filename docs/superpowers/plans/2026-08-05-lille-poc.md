# POC multi-ville Lille — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter Lille comme deuxième ville dans Oracle des Loyers, visible sur la carte du frontend via un sélecteur Lyon/Lille, à partir de vraies données scrapées.

**Architecture:** Un seul pipeline de données combiné (Lyon + Lille dans un même `master_immo_final.csv`, colonne `ville`), déjà supporté par le stockage et le modèle ML (ORA-71). Le nettoyage/quartier (`clean_immo.py`) et la génération de carte (`generate_map.py`) sont généralisés pour reconnaître les deux villes ; la carte reste un fichier HTML statique par ville (Folium), le frontend bascule entre les deux via un sélecteur qui change l'URL de l'iframe.

**Tech Stack:** Python 3.13 (pandas, scikit-learn, folium, Flask), React 18 + Vite (frontend), pytest / vitest.

## Global Constraints

- Portée POC rapide : pas de généralisation complète (pas de reverse-geocoding, `chat_service.py` non touché), voir `docs/superpowers/specs/2026-08-05-lille-poc-design.md`.

- Un seul dataset combiné (`ville` en colonne), pas de pipeline parallèle par ville.
- Aucun changement à `backend/schemas.py` (pas de paramètre `ville` sur `/api/quartier-stats`/`/api/predict`) : les CP Lyon (69xxx) et Lille (59xxx) ne se chevauchent jamais.
- `chat_service.py` non modifié dans ce POC.
- Toujours committer les artefacts de données générés (CSV, HTML, `.pkl`) : convention existante du dépôt (`.gitignore:12-17`), pas de gitignore à ajouter.

```python
def extract_postal_code(text):
    """Normalise le CP (69XXX ou 59XXX)."""
    if pd.isna(text): return "69000"
    text = str(text).lower()
    match_zip = re.search(r'(69\d{3}|59\d{3})', text)
    if match_zip: return match_zip.group(1)
    match_arr = re.search(r'lyon\s*(\d{1,2})', text)
    if match_arr: return f"690{int(match_arr.group(1)):02d}"
    return "69000"
```

(Le fallback par défaut reste `"69000"` : c'est le comportement déjà existant pour Lyon quand aucun CP n'est trouvé — inchangé pour ne pas régresser. Le nouveau motif `59\d{3}` capture les CP Lille explicites, qui sont le cas normal — les scrapers Lille produisent des annonces avec l'adresse/CP dans le texte source.)

def run_fusion():
    dfs = []
    print("\n🏗️  DÉMARRAGE DE LA FUSION...\n")
    villes = load_declared_villes()

    for slug, ville_config in villes.items():
        ville_nom = ville_config['nom']

        # 1. FICHIERS CLASSIQUES
        for config in site_files_config(slug):
            fichier = os.path.join(data_dir, config['file'])
            if os.path.exists(fichier):
                df = pd.read_csv(fichier)
                print(f"--- {ville_nom} / {config['site']} ---")

                new_df = pd.DataFrame()
                new_df['site'] = [config['site']] * len(df)
                new_df['url'] = df[config['col_url']]
                new_df['prix'] = df[config['col_prix']].apply(clean_price_integer)

                full_desc = df[config['text_cols'][0]].fillna('')
                if len(config['text_cols']) > 1:

                new_df['type'] = full_desc.apply(extract_type)

                if config['site'] == 'Orpi':
                    new_df['surface'] = full_desc.apply(clean_surface)
                    new_df['code_postal'] = full_desc.apply(extract_postal_code)
                else:
                    new_df['surface'] = df[config['col_surf']].apply(clean_surface)
                    new_df['code_postal'] = df[config['col_cp']].apply(extract_postal_code)

                new_df['ville'] = ville_nom
                new_df['description'] = new_df['description_raw'].apply(format_description)

                new_df['latitude'] = None
                new_df['longitude'] = None

                if config['site'] == 'Century 21':
                    new_df = new_df.drop_duplicates(subset=['prix', 'surface', 'description_raw'])
                else:
                    new_df = new_df.drop_duplicates(subset=['url'])

                new_df = new_df.dropna(subset=['prix'])
                dfs.append(new_df)
                print(f"   ✅ Ajouté : {len(new_df)} annonces")

        # 2. VIZZIT (fichier GPS séparé)
        vizzit_file = os.path.join(data_dir, f'annonces_{slug}_vizzit_geoloc_complete.csv')
        if os.path.exists(vizzit_file):
            print(f"--- {ville_nom} / Vizzit (GPS) ---")
            df_v = pd.read_csv(vizzit_file)

            v_df = pd.DataFrame()
            v_df['site'] = ['Vizzit'] * len(df_v)
            v_df['url'] = df_v['Lien']

            v_df['description'] = df_v['Details'].apply(format_description)

            v_df['latitude'] = df_v['Lat']
            v_df['longitude'] = df_v['Lon']

            v_df = v_df.drop_duplicates(subset=['url'])
            v_df = v_df.dropna(subset=['prix'])

            print(f"   ✅ Ajouté : {len(v_df)} annonces (avec GPS)")

        master_df = master_df[master_df['prix'] < 3500]
        condition_coloc = (master_df['prix'] < 800) & (master_df['surface'] > 60)

def trouver_quartier(row):
    lat, lon = row['latitude'], row['longitude']
    if pd.isna(row['code_postal']): return "Inconnu"
